# Security Policy

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Report them privately through GitHub instead:
[Report a vulnerability](https://github.com/Azentrius/custarium/security/advisories/new)
(tab **Security → Report a vulnerability** in this repository).

Please include:

- what is affected (component, version or commit),
- steps to reproduce,
- the impact you expect.

We aim to acknowledge reports within 7 days. This is a small project, so a fix
may take longer; we will keep you informed and credit you in the advisory
unless you prefer to stay anonymous.

## Supported versions

There is no release yet. Until the first release, only the latest state of the
`main` branch receives security fixes.
